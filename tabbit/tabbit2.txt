## **🚀 Langkah 1: Perbaiki Routing (Paling Penting)**

Masalah utama saat ini adalah semua user setelah onboarding diarahkan ke `/dashboard` yang isinya hanya untuk Siswa. Kita perlu membuat sistem routing berdasarkan role.

### **A. Buat File Baru: `app/(main)/dashboard/page.tsx` (Sebagai Router)**

Ganti isi file `app/(main)/dashboard/page.tsx` yang sekarang dengan kode berikut. Kode ini akan mengecek role user dan mengarahkan mereka ke halaman yang benar.

```tsx
'use client';
import { useEffect } from 'react';
import { useAuth } from '@clerk/nextjs';
import { useQuery } from 'convex/react';
import { api } from '@/convex/_generated/api';
import { useRouter } from 'next/navigation';

export default function DashboardRouter() {
  const { userId } = useAuth();
  const router = useRouter();
  
  // Ambil data user dari Convex
  const getUser = useQuery(api.users.getUser, userId ? { clerkId: userId } : 'skip');

  useEffect(() => {
    if (getUser) {
      // Redirect berdasarkan role
      switch (getUser.role) {
        case 'student':
          router.replace('/dashboard/student'); // Halaman siswa (gamification)
          break;
        case 'parent':
          router.replace('/parent'); // Halaman orang tua
          break;
        case 'teacher':
          router.replace('/teacher'); // Halaman guru
          break;
        case 'school_admin':
          router.replace('/school'); // Halaman sekolah
          break;
        default:
          router.replace('/onboarding'); // Jika role belum ada, kembali ke onboarding
      }
    }
  }, [getUser, router]);

  return (
    <div className="flex items-center justify-center min-h-screen">
      <div className="animate-spin rounded-full h-12 w-12 border-b-2 border-primary"></div>
      <p className="ml-4 text-lg">Memuat dashboard...</p>
    </div>
  );
}
```

### **B. Pindahkan Halaman Siswa Saat Ini**

File `app/(main)/dashboard/page.tsx` yang sekarang (yang berisi XP, Badges, dll) harus dipindahkan agar tidak tertimpa.

1.  Buat folder baru: `app/(main)/dashboard/student/`
2.  Pindahkan file `app/(main)/dashboard/page.tsx` yang lama ke dalam folder tersebut menjadi `app/(main)/dashboard/student/page.tsx`.
3.  Pastikan path import di dalamnya tetap benar (biasanya sudah oke karena masih dalam struktur `app`).

### **C. Update Onboarding Redirect**

Edit file `app/(main)/onboarding/page.tsx`. Cari bagian `handleSubmit` dan ubah baris `router.replace('/dashboard');` menjadi:

```typescript
// Di dalam handleSubmit, setelah createUser berhasil:
router.replace('/dashboard'); 
// Biarkan tetap /dashboard karena kita sudah membuat router di atas yang akan mengarahkan otomatis.
```
*Catatan: Dengan langkah A & B, redirect ke `/dashboard` sekarang akan aman karena akan otomatis diteruskan ke halaman yang benar.*

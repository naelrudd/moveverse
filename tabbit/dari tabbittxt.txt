## **🔍 Masalah yang Teridentifikasi**

### **1. Role Routing Tidak Berfungsi**
Setelah onboarding, semua user diarahkan ke `/dashboard` yang **selalu menampilkan student view** (gamification, XP, badges, pets), terlepas dari role yang dipilih (student/parent/teacher).

**Bukti dari code:**
- `onboarding/page.tsx` line 73: `router.replace('/dashboard')` — selalu ke dashboard yang sama
- `dashboard/page.tsx` — hardcoded student dashboard dengan XP, badges, pet companions
- `parent/page.tsx`, `teacher/page.tsx`, `school/page.tsx` — sudah ada tapi **tidak terhubung ke routing**

### **2. Dashboard Tidak Sesuai Spesifikasi Tim Produksi**

| Role | Yang Ada Sekarang | Yang Diperlukan |
|------|-------------------|-----------------|
| **Orang Tua** | Weekly family report, PL trend, family challenges ✅ (sudah ada di `/parent`) | Laporan detail perkembangan motorik, akses hasil rekaman kamera AI, rekomendasi cabang olahraga |
| **Anak/Siswa** | Student dashboard dengan XP, badges, pets ✅ (sudah ada di `/dashboard`) | Game interaktif, pencapaian level, poin, reward ✅ |
| **Guru** | Class overview, student heatmap ✅ (sudah ada di `/teacher`) | Data analisis seluruh siswa, kemajuan individu/kelompok, rancang program latihan |
| **Sekolah** | School analytics ✅ (sudah ada di `/school`) | Laporan ringkas performa PJOK seluruh sekolah |

## **🛠️ Rencana Perbaikan Prioritas**

### **Phase 1: Role-Based Routing (CRITICAL)**

#### **1.1 Buat Dashboard Router Component**

Buat file baru `app/(main)/dashboard/router.tsx` yang akan:
- Fetch user data dari Convex
- Redirect ke halaman yang sesuai berdasarkan role:
  - `student` → `/dashboard/student` (rename dari `/dashboard` yang sekarang)
  - `parent` → `/parent`
  - `teacher` → `/teacher`
  - `school_admin` → `/school`

#### **1.2 Update Onboarding Redirect**

Ubah `onboarding/page.tsx` line 73 dari:
```typescript
router.replace('/dashboard');
```
Menjadi:
```typescript
router.replace(`/dashboard/${role}`);
```
